Ingeniero en sistemas. Casi todo lo que programo empieza igual: algo que estaba
haciendo a mano y me cansé de repetir.

a lo que pida el proyecto: React o Vue si es web, Flutter si es móvil, Java o C#
cuando hace falta algo con más peso detrás. Las bases de datos casi siempre acaban
siendo SQL.
